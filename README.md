## 🎮 About the Game

This project is a simple game developed while I was learning **C#**.

I recreated the classic **Flappy Bird** game using **Windows Forms**.

### Game Objective

Control the bird by pressing the **Space key** and avoid hitting the pipes.

The goal is to progress as far as possible without colliding.

---

## ✨ Features

### 🕹️ Gameplay Mechanics

- Bird is controlled using **Space (Jump)**  
- Press **R** to restart the game  
- Gravity-based movement system  

---

### 🚧 Collision System

- Game ends if the bird hits pipes  
- Game ends if the bird touches screen boundaries  

---

### 🏆 Scoring

- +1 score for each pipe passed  
- Score displayed in real time

## ⚙️ Installation

1️⃣ Download or clone the repository:

```bash
git clone https://github.com/cemreeyrtsvr/FlappyBird.git
```

2️⃣ Open with **Visual Studio 2022**

3️⃣ Make sure these image assets are added to the project:

- `bird.png`  
- `pipe.png`  
- `background.png`  

4️⃣ Run the project ▶️ and play.
